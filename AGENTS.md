# Converty contributor instructions

Converty is primarily a native SwiftUI macOS file utility in `macOS/`.
The earlier web edition remains in `src/` as a working reference.
Read `DESIGN.md`, `macOS/README.md`, and `docs/native-architecture.md` for native work.
`docs/architecture.md` covers the web edition only.
The native app's marketing site lives in `site/`; read `site/PRODUCT.md`, `site/DESIGN.md`, and `site/README.md` before changing it.
Build it separately with `npm ci --prefix site` and `npm run build --prefix site`.
Keep its source-release CTA truthful until a signed, notarized app is available.

- Keep `macOS/project.yml` as the XcodeGen source of truth; generated projects and builds are ignored.
- Use native AppKit/SwiftUI controls and system file integrations. Do not substitute a WebView wrapper.
- Run `swift test --package-path macOS` with a supported FFmpeg executable, build with `macOS/Scripts/build.sh`, and verify the actual app for native changes.
- Bundle a self-contained FFmpeg build; do not ship Homebrew library dependencies. Prepare corresponding source and license material before public binary distribution.
- Commit no generated binaries, reference footage, private local paths, or signing credentials.

- Keep file bytes on the user's device.
  Never introduce uploads, analytics, remote conversion endpoints, or remote file persistence without an explicit product decision.
- Preserve original inputs and produce separate outputs. Native outputs use collision-safe names on disk; web outputs are blobs.
- Advertise only implemented formats and operations.
  Put user-relevant limitations in the operation dialog, help, README, and reference feature matrix.
- Never simulate a conversion with a filename change, timer, or fake completion state.
- Keep FFmpeg work serialized and clean up temporary files, subprocesses, and web object URLs.
- Keep web runtime dependencies pinned in `package-lock.json` and self-host processing assets.
- Treat third-party reference sites as research, not a source of code, branding, copy, or assets.
- Shared decisions and research belong in tracked repository documentation.
  Downloaded reference media belongs outside the repository.
- Run `npm run typecheck`, `npm test`, and relevant `npm run test:e2e` coverage before handing off processing changes.
  For web UI changes, check desktop and mobile rendered surfaces.
- Source archive and engine files under `public/` are generated by scripts and must not be manually edited.
