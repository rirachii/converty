Can I download it today?

You can get the source and build Converty locally today. This is an early source release, so there isn’t a signed, notarized installer yet. The build guide lists the tools and steps you need.

Which Macs does it work on?

The app targets macOS 14 or later. The current local build is verified on Apple Silicon with macOS 26. Building requires Xcode 26 or later, XcodeGen, and a self-contained FFmpeg engine. Other supported OS versions still need release testing.

Do my files leave my Mac?

No. Conversion and editing run on your Mac using native frameworks and a bundled media engine. There are no file uploads, accounts, or analytics in Converty.

Where does the converted file go?

Beside the original, by default. You can choose a different folder in the app. Combined outputs, like merged PDFs, go beside the first input file. Converty creates a separate copy and adds a number if that filename is already taken.

Is it really free and open source?

Yes. Converty’s source is available under GPL-3.0-or-later. You can use, study, and modify it under that license. Bug reports, improvements, and contributions are welcome.
