FFmpeg
FFmpeg is copyright its developers and is built with GPL-enabled codecs.
The executable's version, configuration, and build-input hash are in FFmpeg-build.txt.
Release builds use macOS/Scripts/build-engine.py and macOS/Engine/sources.json.
MediaEngineNotices.txt contains the complete upstream notices for FFmpeg and
its statically linked libraries, including x264, libvpx, Opus, LAME, libogg,
libvorbis, and libwebp. MediaEngineSources.json records the source archives
and checksums; MediaEngineProvenance.json records the build and engine hash.
Matching source archives and the build recipe accompany each GitHub release:
https://github.com/rirachii/converty/releases
Upstream: https://ffmpeg.org/

Development builds using a custom FFmpeg input may not have these release
records. Do not redistribute a custom engine without its corresponding
source, build instructions, and third-party notices.

libarchive
Converty uses macOS's system libarchive. C declarations are vendored from
libarchive v3.7.7, under the BSD terms retained verbatim in both header files:
https://github.com/libarchive/libarchive/tree/v3.7.7/libarchive
The public headers are not a bundled copy of the libarchive implementation.

Apple frameworks and SF Symbols are system-provided. Converty does not include
Tangerine code, branding, artwork, or demo footage.
