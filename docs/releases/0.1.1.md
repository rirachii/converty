# Converty 0.1.1

Successful conversions and edits now close the floating progress panel as soon as
the output is saved. The "Your copy is ready" screen and its Done and Show in
Finder buttons are removed. Error panels remain available so you can retry or
choose another output folder. Originals remain untouched.

This is build 4 for Apple Silicon Macs running macOS 14 or later. It includes the
media engine and is ad-hoc signed, without Apple notarization.

The native change passed 19 core tests and was verified in the built app on
macOS 26: image conversion and compression saved real outputs and closed the
panel; an invalid image retained the error and recovery controls.

The GitHub release includes the DMG, application source, corresponding media
engine sources, release manifest, and SHA-256 checksums. Packaging verifies the
disk image, app signature, and payload hashes.

Existing Homebrew users can update with:

```sh
brew update
brew upgrade --cask rirachii/tap/converty
```

For a blocked first launch, follow [Apple's installation instructions](https://support.apple.com/en-us/102445)
if you choose to trust this early release.
